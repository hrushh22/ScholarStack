How ScholarStack works

A retrieval-augmented generation pipeline over three public data sources, built and evaluated in Python and served from free infrastructure: GitHub Pages, Supabase (Postgres + pgvector) and Groq.

ScholarStack · BDA 696 Final Project, San Diego State University · Data: Kaggle resume dataset, LinkedIn job postings 2023–24, O*NET 31.0 (CC BY 4.0, U.S. DOL/ETA) · Reference resumes are examples to learn from; only include experience you actually have.
