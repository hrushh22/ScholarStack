How well does it work?

We tested each part of the system on 240 job postings that we set aside at the start and never used while building it. Every number here can be reproduced from the scripts in the repo.

Method

How it works

The heavy work (cleaning 124k postings, building the indexes, running the experiments) happens offline in Python. This site is static and hosted on GitHub Pages. When you hit Generate, your browser does the embedding, a small Supabase backend finds the evidence, and an open-weight model on Groq writes the draft.
